# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Report vulnerabilities privately by emailing [mohammadhprp@gmail.com](mailto:mohammadhprp@gmail.com). Please include as much of the following information as possible:

- A description of the vulnerability and its potential impact
- The affected package version or versions
- Steps to reproduce the issue or a proof of concept
- Relevant configuration, environment, and dependency details
- Any suggested mitigation or fix

Security reports will be reviewed confidentially. Please allow reasonable time for investigation, remediation, and coordinated disclosure before making the vulnerability public.

## Scope

This policy applies to the `mohammadhprp/filament-ip-to-country-flag-column` package and its source code hosted at [github.com/mohammadhprp/filament-ip-to-country-flag-column](https://github.com/mohammadhprp/filament-ip-to-country-flag-column).

For vulnerabilities in Laravel, Filament, or another dependency, please report the issue to the relevant project maintainer as well.
